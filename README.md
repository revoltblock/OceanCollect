🌊 OceanCollect

极简 · 全能 · 媒体收藏助手

OceanCollect 是一款轻量级的在线媒体管理工具，帮助您在不同来源之间快速检索、预览和收藏您喜爱的影视与多媒体内容。无需安装，打开即用。

---

💡 核心能力

· 多源聚合
  一键切换数据来源，统一展示结果，告别在多个网站间反复切换。
· 快捷预览
  点击卡片即可查看封面、标题、演员、时长等关键信息，并支持在线视频播放。
· 云端收藏
  将喜欢的作品一键保存到收藏夹，支持云端持久化存储，随时随地访问。
· 全平台适配
  深色主题，响应式设计，在手机、平板、桌面设备上均能流畅使用。

---

🧭 如何使用

1. 访问 OceanCollect 页面。
2. 输入关键词（如片名、番号或演员名），选择数据源，开始搜索。
3. 在结果列表中浏览，点击卡片获取详情或预览视频。
4. 点击“收藏”将内容加入您的个人收藏库。
5. 切换到“我的收藏”查看所有已保存的项目。
